Layer 1: Bootstrap (`terraform/bootstrap`) — ~3 mins

Provisions the encrypted S3 remote state bucket with Object Lock and DynamoDB locking table to safeguard against concurrent Terraform operations.

terraform 
resource "aws_s3_bucket" "terraform_state" {
  bucket        = "ray-platform-tfstate-${data.aws_caller_identity.current.account_id}"
  force_destroy = false
}

resource "aws_s3_bucket_server_side_encryption_configuration" "state_crypto" {
  bucket = aws_s3_bucket.terraform_state.id
  rule {
    apply_server_side_encryption_by_default {
      sse_algorithm = "aws:kms"
    }
  }
}

resource "aws_dynamodb_table" "terraform_locks" {
  name         = "ray-platform-tf-locks"
  billing_mode = "PAY_PER_REQUEST"
  hash_key     = "LockID"
  attribute {
    name = "LockID"
    type = "S"
  }
}

Spot Instance Resiliency Mechanics

How the platform survives Spot preemption without losing data or failing the pipeline execution:

1. 12 Capacity Pools

Diversifying across 4 instance types and 3 AZs creates 12 distinct capacity pools, dropping spot eviction risk to <5%.

2. 2-Minute Warning Drain

AWS Node Termination Handler catches EventBridge interruption notices, cordoning the node and safely flushing Ray tasks.

3. Object Store Lineage

Ray tasks use `@ray.remote(max_retries=3)`. Intermediate Apache Arrow object blocks are reconstructed automatically from upstream data.

Kubernetes Network Isolation

Ray workers communicate internally on port 6379, completely blocked from external ingress. Only egress to VPC endpoints is permitted.

yaml 
apiVersion: networking.k8s.io/v1
kind: NetworkPolicy
metadata:
  name: ray-isolation
  namespace: ray-workloads
spec:
  podSelector:
    matchLabels:
      app.kubernetes.io/name: ray-worker
  policyTypes: ["Ingress", "Egress"]
  ingress:
    - from:
      - podSelector:
          matchLabels:
            app.kubernetes.io/name: ray-head
      ports:
        - protocol: TCP
          port: 6379

def write_to_iceberg(df: pd.DataFrame, catalog, table_name="corporate_registry"):
    """ACID transactional merge into Apache Iceberg lakehouse."""
    table = catalog.load_table(f"corporate_data_db.{table_name}")
    table.upsert(df)
    snapshot = table.current_snapshot()
    return snapshot.snapshot_id
